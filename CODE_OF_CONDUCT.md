# Verhaltenskodex

open-spri lebt von der Zusammenarbeit von Menschen aus unterschiedlichen Unternehmen: Netzbetreibern, Diensteanbietern und Softwareherstellern, die im Markt teils Wettbewerber sind. Hier arbeiten wir sachlich und respektvoll zusammen.

## Erwartet wird

- Respekt und Freundlichkeit gegenüber allen Beteiligten, unabhängig von Herkunft, Geschlecht, Alter, Behinderung, Erfahrung oder Arbeitgeber
- Sachliche, begründete Kritik an Code und Konzepten, nicht an Personen
- Offenheit für andere Auslegungen der Spezifikation. Im Zweifel entscheidet die Quelle (siehe CLAUDE.md, Grundsatz 2).
- Vertraulichkeit: keine Kunden-, Vertrags- oder Partnerdaten in Issues, Pull Requests oder Diskussionen

## Nicht geduldet werden

- Beleidigungen, Belästigung, diskriminierende Äußerungen
- Veröffentlichung privater Informationen anderer
- Nutzung des Projekts für Werbung oder zur Herabsetzung von Wettbewerbern

## Durchsetzung

Verstöße können an die Maintainer gemeldet werden: über GitHub oder an **abuse@rsm-freilassing.de**. Die Maintainer können Beiträge entfernen und Personen vorübergehend oder dauerhaft vom Projekt ausschließen.

Angelehnt an den [Contributor Covenant 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).
