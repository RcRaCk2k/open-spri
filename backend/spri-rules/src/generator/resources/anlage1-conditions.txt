# Conditions from the column "Anmerkung" of Anlage 1 that the cardinality columns cannot express.
# Each entry quotes its source row. Format:
#
#   <sheet>:<label path> = only GF <list>    attribute exists only in these business cases (else: not allowed)
#   <sheet>:<label path> = not GF <list>     attribute not allowed in these business cases
#   <sheet>:<label path> = only AKZ <list>   attribute exists only for these change indicators (else: not allowed)
#   <sheet>:<label path> = choice            alternative of an XSD choice: the mandatory part is checked by the
#                                            choice row, the alternative itself is optional (minimum 0)
#
# GF uses the values of the messages (NEU, KUE-AG, KUE-LE, AEN-LMAE, LAE, PV, EST, GET, SET).
# Every entry must be used; the build fails otherwise.
